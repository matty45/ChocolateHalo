A WIP multi-platform port of the January 2002 Halo CE xbox decompilation.

The goal of this port is to be the Halo 1 equivalent of [Chocolate Doom](https://github.com/chocolate-doom/chocolate-doom/blob/master/PHILOSOPHY.md). Prioritzing faithfulness yet compatible with modern platforms.

Secondary goal is to backport all the changes from the retail versions of Halo 1 on the xbox.
